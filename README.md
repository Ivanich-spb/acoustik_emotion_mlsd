# Acoustic Stress & Emotion Monitor

Учебный проект курса **ML System Design**. Репозиторий содержит дизайн
и (по мере выполнения домашних заданий) реализацию MVP-системы, которая
по записям рабочих аудиозвонков определяет признаки стресса и
эмоциональное состояние сотрудников линии поддержки некоторой
организации.

> Проект учебный: часть моделей и итоговая интегральная оценка в
> реальных постановках такого рода задач закрыты NDA заказчика и здесь
> представлены заглушками/baseline-эвристиками — см. дизайн-документ.

## Задача

По аудиозаписи рабочего звонка сотрудника с клиентом система должна:

- извлечь акустические признаки речи (тон, темп, паузы, джиттер,
  шиммер и т.п.);
- определить эмоции по аудио- и текстовому каналу (распознавание
  речи → эмоции по транскрипту);
- агрегировать признаки в единую оценку эмоционального
  состояния/уровня стресса за звонок;
- сохранить результат для последующей агрегации по сотруднику.

Полная постановка задачи, бизнес-требования, скоуп итерации и
архитектура — в [`docs/ml_system_design_doc.md`](docs/ml_system_design_doc.md).

По мере выполнения следующих ДЗ сюда добавится код сервисов (`src/`),
тесты и инфраструктурные файлы.

## Окружение и качество кода

Используется [ruff](https://docs.astral.sh/ruff/) как линтер и
форматтер, и [pre-commit](https://pre-commit.com/) для автоматической
проверки перед коммитом.

```sh
pip install ruff pre-commit
pre-commit install
```

Прогнать проверки вручную на всём репозитории:

```sh
pre-commit run --all-files
```

## Работа над заданиями

Каждое домашнее задание выполняется в отдельной ветке `hw_n` и
сдаётся отдельным pull request'ом в `main`.
